Dashboard de Análise de Vendas Porsche

Sobre o projeto

Este projeto foi desenvolvido como parte de uma atividade de curso e tem como objetivo analisar os dados de vendas da Porsche por meio de um dashboard interativo.

O dashboard permite explorar informações de vendas por modelo, cidade, ano do modelo e forma de pagamento, facilitando a visualização dos resultados e a comparação entre diferentes grupos.

Perguntas de negócio

- Quais são os modelos da Porsche mais vendidos em cada cidade?
- Quais são as formas de pagamento mais utilizadas em cada cidade?
- Qual é o valor médio de venda em cada cidade?

Indicadores e funcionalidades

- Total de vendas.
- Receita total.
- Ticket médio.
- Modelo líder de vendas.
- Gráfico de barras dos modelos mais vendidos por cidade.
- Gráfico de pizza com a distribuição das formas de pagamento.
- Comparativo do ticket médio por cidade.
- Filtros interativos para modelo Porsche, ano do modelo, cidade e forma de pagamento.
- Insights atualizados conforme os filtros selecionados.

Ferramentas utilizadas

- ChatGPT com Canvas: desenvolvimento do dashboard a partir de prompts escritos por mim.
- HTML: estrutura do dashboard.
- Git e GitHub: versionamento e armazenamento do código.
- GitHub Pages: publicação do dashboard na internet.

Processo de desenvolvimento

Inicialmente, defini as perguntas de negócio, os indicadores e os filtros que gostaria de visualizar no dashboard. Em seguida, utilizei o ChatGPT com Canvas para gerar a primeira versão em HTML, orientando a criação de uma interface elegante e refinada, inspirada na identidade visual da Porsche.

Após analisar a primeira versão, solicitei melhorias nos gráficos e nas comparações entre cidades, incluindo o ranking dos modelos mais vendidos, a distribuição das formas de pagamento e o comparativo do ticket médio.

Tratamento dos dados

A base de dados foi disponibilizada pelo curso. Os valores monetários são apresentados em dólares americanos (USD), conforme a base original.
